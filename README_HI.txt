WinGo Auto Trader — शुरुआती Android प्रोटोटाइप

इस ZIP में Android Studio प्रोजेक्ट और assets/index.html शामिल है।
ऐप में 30 सेकंड, 1, 2, 3 और 5 मिनट के टाइमर मोड, वेबसाइट सूची, सिम्युलेटेड विश्लेषण और केवल डेमो ट्रेडिंग UI है।

महत्वपूर्ण सीमाएँ:
- यह APK नहीं है; यह APK बनाने योग्य Android Studio source project है।
- यह किसी गेम वेबसाइट से लाइव डेटा नहीं पढ़ता और असली बेट/ट्रेड नहीं लगाता।
- लाइव स्कैनिंग के लिए प्रत्येक वेबसाइट की अनुमति प्राप्त आधिकारिक API/दस्तावेज़ आवश्यक हैं।
- डेमो सिग्नल और डेमो जीत/हार यादृच्छिक सिमुलेशन हैं; इन्हें भविष्यवाणी न समझें।
- पासवर्ड, OTP, API secret या Telegram bot token इस ऐप में न डालें।

APK बनाने के लिए कंप्यूटर पर Android Studio में इस फ़ोल्डर को Open करें, Gradle Sync करें, फिर Build > Build APK(s) चुनें।
